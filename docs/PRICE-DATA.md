FE는 일반 구매 예시의 즉시할인 31,800원과 삼성 개인신용카드 결제 할인 30,396원만 반영했습니다. 중복 적용 여부가 확인되지 않은 쿠폰은 합산하지 않았습니다. 다른 모델도 보상판매·포인트·보험 등의 가치를 임의로 합산하지 않습니다.

할부 원금과 카드 청구 혜택의 구분을 확정할 수 없는 가격은 cashOnly로 표시합니다. 사용자가 조건을 확인한 후 일시불 총비용 비교에만 적용합니다. 할부 비교는 직접 입력으로 전환한 뒤 실제 계약 원금과 이율을 입력합니다. 가격 선택 시 기존 기기/지원금/쿠폰/카드 할인을 초기화하여 중복 차감을 막습니다.

Apple 및 일부 삼성 모델의 할인 정보가 비어 있는 것은 최대 할인 미확인을 뜻하며, 할인 불가를 뜻하지 않습니다. 통신사 지원금은 가입 방식·요금제·번호이동·판매점·확인 시점별로 달라 확정할 수 없었던 값을 자동 입력하지 않습니다.

## 갱신 방법

1. 제품 공식 페이지의 모델 코드, 용량, 가격, 색상, 카드·쿠폰·가입 조건과 행사 종료일을 확인합니다.
2. catalog의 retail, netPrice, condition, source, checkedAt, validUntil을 수정합니다.
3. 조건이 불명확하면 offers를 비워 두고 직접 입력을 제공합니다. 기존 가격을 최신이라고 다시 날짜만 바꾸지 않습니다.
4. `npm test`, `npm run build`, `npm run check` 후 배포합니다.

조건부 할인 선택은 한국 날짜 기준 행사 종료 또는 확인일로부터 7일 초과 시 비활성화됩니다. 이번 데이터의 확인기간은 2026-09-30까지입니다. 기준가는 확인일과 함께 남습니다. 이미 저장하거나 공유한 견적은 과거 입력 시나리오이므로 자동 변경하지 않습니다. 자동 가격 갱신 작업은 현재 구현하지 않았습니다.
